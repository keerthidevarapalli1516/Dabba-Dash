# 🍔 Dabba Dash

### Smart Food Ordering and Delivery Management System

Dabba Dash is a web-based food ordering and delivery management project designed to make food delivery faster, easier, and more efficient.

Our main aim is to achieve a **20-minute food delivery target** by improving order management, monitoring kitchen operations, and organizing delivery activities through a centralized dashboard.

The system helps identify delays in the kitchen and provides timely alerts when an order exceeds the expected preparation time.

## Features

- **Dashboard:** Displays important information about active orders, average preparation time, dispatched orders, and available riders.
- **Order Management:** Helps manage and monitor food orders efficiently.
- **Multi-Order Management:** Organizes multiple orders for smoother kitchen operations.
- **Rider Management:** Helps monitor delivery riders and their availability.
- **Delivery Zones:** Organizes delivery areas for better coordination.
- **Customer Tracking:** Provides customer and delivery-related information.
- **Trip Calculator:** Helps calculate delivery trip details.
- **Kitchen Bottleneck Detection:** Identifies orders that are taking longer than expected and helps locate delays in kitchen operations.
- **20-Minute Delay Alerts:** Sends an alert when an order has been in the kitchen for more than 20 minutes, helping the team take timely action.
- **User-Friendly Interface:** Provides simple navigation and an organized dashboard for easier management.

## Run Locally

No additional installation is required for this frontend project.

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to run the website locally.
